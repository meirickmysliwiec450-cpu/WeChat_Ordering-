# 微信点餐系统 - 商家管理后台（前端）

基于 Vue 3 + Vite + Element Plus 的微信点餐系统商家端管理后台，为餐厅管理者提供直观的数据仪表盘和完整的店铺运营管理功能。

---

## 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue 3 | 3.5.x | 前端框架（Composition API + `<script setup>`） |
| Vite | 8.0.x | 极速构建工具 |
| Element Plus | 2.14.x | 企业级 UI 组件库 |
| Vue Router | 5.0.x | 前端路由管理 |
| Pinia | 3.0.x | 轻量级状态管理 |
| Axios | 1.17.x | HTTP 请求库 |

## 已完成功能

### 1. 管理员登录
- 美观的渐变背景登录页
- 表单验证（账号、密码必填）
- 登录成功后 Token 自动存入 localStorage
- 默认账号 `admin / 123456` 预填充，方便快速登录
- 已登录状态自动跳转仪表盘

### 2. 数据仪表盘
- **4 张统计卡片**：用户总数、订单总数、总营业额、菜品数量，以图标+数字+标签形式展示
- **订单状态分布**：待处理、已接单、已完成三种状态的占比
- **今日速览**：今日订单数、待处理反馈数
- 页面加载时自动请求后端统计接口

### 3. 用户管理
- 用户列表分页展示（ID、昵称、OpenID、手机号、性别、注册时间）
- 启用/禁用用户账号（一键切换用户状态）

### 4. 分类管理
- 分类列表展示（分类名称、排序号）
- 新增分类弹窗
- 编辑分类信息
- 删除分类（确认提示）

### 5. 菜品管理
- 菜品列表分页展示（名称、分类、价格、库存、折扣、销量、状态）
- **分类筛选**下拉框 + **关键词搜索**输入框，快速定位菜品
- 新增/编辑菜品弹窗（名称、分类下拉选择、价格、库存、折扣、图片URL、描述）
- 上架/下架状态切换
- 删除菜品（确认提示）

### 6. 订单管理
- 订单列表分页展示（订单号、用户名、金额、支付状态、订单状态、时间）
- **订单状态筛选**：全部 / 已取消 / 待处理 / 已接单 / 已完成
- **订单状态操作**：接单 → 完成；拒单
- 点击查看订单详情

### 7. 订单详情
- 展示订单完整信息（订单号、当前状态、支付状态、收货人、电话、地址、备注、金额、下单时间）
- 订单明细表格（菜品名称、单价、数量、小计），自动计算合计金额

### 8. 轮播图管理
- 轮播图列表展示（标题、图片URL、跳转链接、排序、状态）
- 新增/编辑弹窗（标题、图片URL、跳转链接、排序号、备注）
- 启用/禁用状态切换
- 删除轮播图（确认提示）

### 9. 用户反馈管理
- 反馈列表分页展示（用户ID、内容、回复内容、处理状态）
- **状态筛选**：全部 / 未处理 / 已回复 / 已解决
- **管理员回复**弹窗（输入回复内容保存后自动标记为"已回复"）
- 标记已解决

采用经典后台管理布局：

## 路由设计

| 路径 | 页面 | 认证 | 说明 |
|------|------|------|------|
| `/login` | 登录页 | 否 | 唯一公开页面 |
| `/dashboard` | 仪表盘 | 是 | 首页 |
| `/users` | 用户管理 | 是 | 用户列表 |
| `/categories` | 分类管理 | 是 | 菜品分类 |
| `/dishes` | 菜品管理 | 是 | 菜品 CRUD |
| `/orders` | 订单列表 | 是 | 订单管理 |
| `/orders/:id` | 订单详情 | 是 | 查看订单明细 |
| `/banners` | 轮播图管理 | 是 | 首页广告位 |
| `/feedbacks` | 反馈管理 | 是 | 用户反馈处理 |

**路由守卫**：未登录访问任何受保护页面自动跳转到 `/login`；已登录访问 `/login` 自动跳转到 `/dashboard`。

---

## Axios 拦截器

- **请求拦截器**：自动从 localStorage 读取 Token 注入 `Authorization: Bearer xxx` 请求头
- **响应拦截器**：统一处理 401 未授权状态（清除 Token 并跳转登录页），其他错误自动弹出 Element Plus 消息提示

## 启动方式

```bash
# 安装依赖
npm install

# 启动开发服务器（热更新）
npm run dev

# 生产环境构建
npm run build
```

前端运行在 **http://localhost:5173**，后端需运行在 **http://localhost:8080/api**。
