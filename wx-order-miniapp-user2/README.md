# 微信点餐系统小程序端前端

本项目是微信点餐系统的顾客端前端，可直接用微信开发者工具导入运行。当前版本使用本地模拟数据和 `wx.setStorageSync` 存储购物车、订单、个人信息与反馈记录，便于先完成界面展示和流程演示。

## 已实现功能

- 首页：展示系统入口、搜索入口、热销菜品。
- 菜单：按类目查看菜品，支持加入购物车。
- 搜索：按菜品名称、描述、标签搜索。
- 购物车：修改数量、填写取餐信息、提交订单、模拟支付。
- 订单：查看全部订单，支持继续支付、取消订单、确认收餐、删除订单。
- 个人中心：修改昵称、手机号、默认取餐/配送信息。
- 菜品反馈：提交商品信息、口味、价格库存、配送服务等反馈。

## 运行方式

1. 打开微信开发者工具。
2. 选择「导入项目」。
3. 项目目录选择本文件所在文件夹。
4. AppID 可使用测试号或选择游客模式。
5. 导入后点击「编译」即可运行。

## 登录接口

- 登录页路径：`pages/login/login`。
- 未登录访问首页、菜单、搜索、购物车、订单、个人中心、反馈页时，会自动跳转到登录页。
- 登录时先调用 `wx.login` 获取 `code`，再向后端发送 `POST /wx/user/login`。
- 后端服务地址在 `app.js` 的 `globalData.baseUrl` 中配置。
- 登录接口建议返回 `token`，支持的常见格式包括 `{ "token": "..." }`、`{ "data": { "token": "..." } }`、`{ "data": { "accessToken": "..." } }`。


## 新版下单流程

- 首页必须先选择堂食或外送。
- 菜单页底部显示购物栏，可增删菜品、计算总价，并进入结算页。
- 结算页会根据堂食/外送显示不同信息：堂食填写堂食备注，外送填写或选择地址。
- 已完成订单可在订单页点击“照片反馈”，进入反馈页上传照片并填写描述。
